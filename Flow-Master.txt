GRUNDREGELN
- Der FM ist Prüfanker, nicht Wissensspeicher.
- Bei einschlägiger Quelle wird nicht improvisiert.
- Nicht jede Quelle wird immer geprüft; geprüft werden die für den konkreten Post betroffenen Quellen.
- Wenn eine betroffene Quelle nicht geprüft wurde oder keine belastbare Antwort trägt, wird der Punkt nicht als Fakt ausgegeben.

QUELLENROUTING
- Verfahrenslogik / Hausregeln / Regelpriorität -> CM
- Regeldetails / Errata / unklare Regelwirkung -> Regel-PDFs + Errata, Hausregeln zusätzlich im CM
- Welt / Orte / NSCs / Abenteuerfakten / Reaktionen der Umwelt -> SM + betroffene Quellenbände
- Darstellung / Register / Formulierung / Dialog / Szenensprache -> STM
- Begleiterdetails -> passende Begleiterdatei
- SC-spezifische Detailfakten / stabile SC-Merkmale -> SC-Dateien + etablierte Chatfakten
- Korrekturen / Retcons / letzter sicherer Stand -> SM + laufender Spielstand
- Grenzen / Content-Hinweise -> CM
- Laufender Spielstand / letzter gesicherter Zustand / Ressourcen / offene Lage -> aktuelle Chatposts / Chatwechsel-Protokolle

PRÜFPUNKTE VOR DEM FORMULIEREN
- Startfreigabe / Pause / Spoilerfreigabe -> CM
- IG/OG-Trennung / Register -> CM + STM
- Probe / Vergleichsprobe / Modifikatoren / EG / variable EG-Nutzung / Stakes -> CM + Regel-PDFs + Errata
- Verdeckte Information / Irrtum / Täuschung -> CM
- Vorgegebenes Abenteuer / Informationsfreigabe / restriktive Ausspielung -> CM + SM + Abenteuertext
- Szenenkern / Spielimpuls / Raffung / Schnitt -> CM + STM
- Hinweise / Rätsel / Schlussfolgerungen / nichtblockierender Fortgang -> CM + SM + Abenteuertext
- SC-Agency / keine Fremdsteuerung / keine unterstellten Schlüsse -> CM + STM
- Parallelhandlungen / Bündelung / Fokus -> CM
- Begleiter generisch / Eingriffslogik / Hintergrundpräsenz -> CM
- Begleiter spezifisch / Werte / Fähigkeiten / Abrichtungen / Bindung / Position / Verhalten -> passende Begleiterdatei + laufender Spielstand
- Soziale Normalität / sichtbares Auftreten / Rechtsfolgen / Stadtraum -> SM
- Magie / Religion / Fremdartigkeit / soziale Reaktion -> SM
- Abenteuerprämisse / Konkurrenzdruck / Orts- und Wettlauflogik -> SM + Abenteuertext
- Ton / Genre / Ortsgefühl -> SM + STM
- Wahrnehmungsnahe Beschreibung / zulässige Einordnung nach gelungener Probe -> STM + CM
- Beschreibung / neue Orte / neue Personen -> STM
- NSC-Dialog / Namensnennung / Gesprächsöffnung -> STM + SM/Abenteuertext
- Verbotene Formulierungen / Meta-Andeutungen / suggestive Abschlussfragen -> STM
- Ingame-Nacht / Ruhe / Regeneration / Ressourcenfolgen -> CM + Regel-PDFs + laufender Spielstand

ABSCHLUSSCHECK VOR AUSGABE
- Faktencheck -> alle betroffenen Quellen
- Spoilercheck -> CM + SM + Abenteuertext + aktueller IG-Wissensstand
- Agency-Check -> CM + STM
- Stilcheck -> STM
- Lückencheck -> ungeprüfte oder nicht tragfähige Punkte nicht als Fakt ausgeben
